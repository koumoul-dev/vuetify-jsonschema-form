# v3 to v4

The old documentation for v3 is still available
[here](https://koumoul-dev.github.io/vuetify-jsonschema-form/3.x/).

VJSF v4 is simply a port to Vuetify 4. There are no known VJSF breaking
changes on our side: simply upgrade as part of the process of
[upgrading from Vuetify 3 to 4](https://vuetifyjs.com/en/getting-started/upgrade-guide/#multi-step-migration).
